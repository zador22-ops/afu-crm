## Нова група `app`

```
https://xdeg-kg7i-jjtu.f2.xano.io/api:BTbEmLYm
```

Авторизація та сама, що для `users_fans/*` у Default: `Authorization: Bearer <токен вболівальника>`.
Без токена — 401.

### `GET /me/topics`

Повертає масив тем, завжди непорожній. Поки людина нічого не вибирала, віддаються всі п'ять.

```json
["favorites", "live", "top", "news", "updates"]
```

### `PATCH /me/topics`

```json
{ "topics": ["favorites", "top", "news"], "platform": "android" }
```

- `topics`: які теми ввімкнені. Порядок неважливий. Невідома назва чи повтор → 400.
  Порожній масив `[]` означає «усі ввімкнені». Щоб вимкнути все, користуйтеся головним
  перемикачем, як зараз (`users_fans/switchNotifications`).
- `platform`: `ios` або `android`. **Надсилайте на кожному запуску разом із темами.** Без неї
  пуш про нову версію людині не прийде: Expo-токен платформи не містить.
- Відповідь така сама, як у GET.

| Тема | Перемикач у профілі | Що приходить |
|---|---|---|
| `favorites` | Улюблені команди | Початок, голи, картки, фоли, перерва, фінал, склад, новий час, нагадування за годину — для матчів команд, матчів і гравців з улюблених |
| `live` | Онлайн-матчі | «Матч почався» для будь-якого матчу |
| `top` | Топ-матч туру | Нагадування за годину до матчу з `is_top` |
| `news` | Новини АФУ | Кожна опублікована новина, один раз |
| `updates` | Нові версії застосунку | Нова major/minor-версія в магазині своєї платформи |

## Формат пуша

```json
{
  "title": "Авалон — СкайАп",
  "body": "⚽ Гол! Ліфер (СкайАп), 7′ · 1:5",
  "data": { "match_id": 509 },
  "sound": "default",
  "richContent": { "image": "https://xdeg-kg7i-jjtu.f2.xano.io/vault/…/логотип.png" }
}
```

- `data.match_id` — відкрити матч. `data.news_id` — відкрити новину. `data.update` (`ios` | `android`)
  разом із `data.version` — відкрити сторінку в магазині.
- Картинка — емблема суперника тієї команди, за якою стежить людина. Якщо людина стежить за обома
  командами або за жодною, показується емблема змагання. Expo передає її як `richContent.image`.
- Виділити жирним команду в рахунку текст пуша не дозволяє, тому команда стоїть у дужках після
  гравця.

Тексти, як вони виходять на справжньому матчі 509:

| Подія | body |
|---|---|
| Початок | `🔴 Матч почався · Екстра-ліга · 6-й тур` |
| Гол | `⚽ Гол! Ліфер (СкайАп), 7′ · 1:5` (також «Автогол!», «Гол з пенальті!», «Гол з дабл-пенальті!») |
| Картка | `🟨 Жовта картка · …`, `🟨🟥 Друга жовта · Суворов (Авалон), 26′`, `🟥 Червона картка · …` |
| Не забитий пенальті | `❌ Не забитий пенальті · …` |
| П'ятий фол | `⚠️ Пʼятий фол · Авалон · 1-й тайм` |
| Перерва / другий тайм | `⏸ Перерва · 1:5`, `▶️ Другий тайм · 1:5` |
| Кінець | `🏁 Кінець матчу · 1:5` |
| Новий час / перенесено | `⏰ Змінено час · тепер сб, 3 жовтня, 17:00` |
| За годину | `⏳ Початок за годину · Екстра-ліга · 6-й тур` (для топ-матчу — `· топ-матч туру`) |
| Склад | `📋 Склад СкайАп оголошено · Екстра-ліга · 6-й тур` |
| Новина | заголовок — назва новини; body — `📰 Новина АФУ · <анонс>` |
| Версія | `Вийшло оновлення`; body — текст про користь із `app_version_note` або запасний «Нова версія … уже в Google Play / App Store» |

## Чого сервер не робить

- **Старий ADMIN** (Default, `zaiuavkaPOST_list`, події з #62 тощо) шле пуші старими функціями #6–#8
  у старому форматі. Default ми не міняємо, тож поки делегати на старому ADMIN, частина пушів
  приходитиме по-старому і без урахування тем.
- **Чинна задача `notificationsScheduleMatchReminder`** (старий формат, за 30 хв, усім улюбленим)
  працює далі. Після ввімкнення живого режиму вболівальник отримає два нагадування — за годину
  й за 30 хв. Вимкнути стару задачу вирішує Андрій.
- **Версія Android береться з `Variables` 6** — це той самий запис, що для глухого екрана
  «Потрібне оновлення». Зараз там `v.1.54.0`, а в Play уже 1.55.0. Пуш про версію Android
  спрацює лише тоді, коли цей запис піднімуть.
