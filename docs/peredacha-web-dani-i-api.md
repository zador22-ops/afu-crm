# Для команди нового сайту futsal.com.ua: дані й API АФУ, що змінились 24–27.09.2026

Доповнення до `docs/peredacha-web-novyny.md` (новини). Тут усе інше, що сайт читає з Xano:
змагання, турніри, матчі, таблиці, клуби, гравці, статистика. Джерело істини по роботах —
реєстр `docs/roadmap/zminy-2026-09-24.md` у репозиторії застосунку `zador22-ops/afu-futzal`.

## 1. Найважливіше: не читайте базу через токен Metadata API

У запиті afu-crm#1 сказано, що сайт бере всі дані через доступ Metadata API. Цей токен відкриває
**весь воркспейс**, включно з таблицями `Users` (адміністратори, паролі-хеші) і `Users fans`
(пошти вболівальників). Якщо він потрапить у код сайту чи в збірку, це витік персональних даних.

Для читання є публічна група **Default** без авторизації, з якої читає фан-застосунок:

```
https://xdeg-kg7i-jjtu.f2.xano.io/api:DSaYr0P-
```

Усе, що нижче, доступне там. Якщо чогось бракує — пишіть в issue, зробимо новий ендпоінт
(лише додаванням, чинні не змінюються). Токен Metadata API просимо з сайту прибрати.

## 2. Ендпоінти групи Default, корисні сайту

| Ендпоінт | Що віддає |
|---|---|
| `GET seasons/overview` | Сезони → змагання: `leagues_id` (турнір сезону), `league_id` (змагання), `name`, `short_name`, `type` («ліга» / «кубок» / «міжнародне»), `main`, `relevance`, `has_table`, `has_bracket`, `table_stage_id`, `sort_order`, `logo` (url або null), `league_short_name` (назва без року), **`show_in_app`** (галочка CRM «показувати у списках вибору»; матчі й таблиці схованого змагання лишаються доступними) |
| `GET matches/upcoming?days=N&leagues=` | Незіграні матчі від початку київської доби на N днів уперед; елемент містить `is_top`, `_league` (однина), `_teaminfo1/2` з `TeamName`, `TeamLogo`, **`team_kind`**, **`country`** |
| `GET matches/recent?days=N&leagues=` | Зіграні за N днів назад, та сама форма |
| `GET matches/top` | Один матч, позначений в CRM як «Топ-матч дня» (`is_top`), або **`null` з HTTP 200** — ніколи 404 |
| `GET match/{id}` | Картка матчу з джойнами команд, турніру, туру, арени, статусу, суддів |
| `GET match/countsByKyivDay/{від}/{до}/{leagues_id}` і `GET match/byKyivDay/{дата}/{leagues_id}` | Календар: кількість матчів по днях і матчі дня **за київською добою** (старі `NumberEachDayOfMonth`/`getMatchsByDay` рахують за UTC, їх не використовуйте). `leagues_id` 0 = усі |
| `GET table/byLig/byStageId?LeagueID=&league_stage_id=` | Турнірна таблиця етапу, з `_zone` (плей-оф, пониження) |
| `GET statistic/scorers/{leagues_id}/{is_bombardir}`, `statistic/cards_v2/{leagues_id}`, `statistic/penalties`, `statistic/double_penalties` | Лідери турніру. **З 26.09 рахуються за протоколом матчу**, а не за заявкою: раніше сезон 2026/27 показував 42 голи з 96 |
| `GET statistic/byTeam/{leagues_id}/{teaminfo_id}` | Гравці команди в турнірі: `games`, `goals`, `assists`, `yellow`, `red` |
| `GET statistic/ByMatch_id/{match_id}` | Події матчу (голи, картки, пенальті) |
| `GET club/{teaminfo_id}`, `GET teaminfo/byLigID/{leagues_id}` | Клуб і клуби турніру |
| `GET people/{id}/statistic`, `GET GetPeopleByID` | Гравець і його статистика |
| `GET search/v2?q=` | Пошук команд і людей **без** суперників збірної й закордонних клубів (старий `search` їх покаже) |
| `GET matches/byTeam`, `GET h2h`, `GET matches/byReferee`, `GET league_stage/current`, `GET tours/current` | Матчі команди, очні зустрічі, матчі судді, поточний етап і тур |

Усі ендпоінти з контрактними знімками в `apis/__fixtures__/xano/` репозиторію застосунку — там
видно точну форму відповіді.

## 3. Що змінилось у даних

- **Змагання (`league`)**: тип «міжнародне»; нові змагання «Збірна України» (6) і «Ліга чемпіонів» (7)
  з турнірами 2026/27 (13 «ЗБ», 14 «ЛЧ»); «Кубок України» (4) з турніром 12 «КУ»; «Вища ліга
  (жінки)» (5) — змагання є, турніру ще нема; «Кубок Нескорених» (3) — торішній. Порядок
  `sort_order`: ЗБ 1, ЛЧ 2, ЕЛ 3, ПЛ 4, КУ 5, ВЛ(ж) 6, КН 7.
- **Галочка `show_in_app`**: адміністратор зняв її зі Збірної, ЛЧ і Кубка Нескорених — у списках
  вибору застосунку їх нема до наповнення. Сайту радимо поводитись так само.
- **Логотипи змагань** — лише ті, що адміністратор заливає через CRM (`league.logo`, приходить у
  `seasons/overview` як `logo`). Емблема одна на змагання, спільна для всіх сезонів.
- **Назви турнірів**: рік у форматі «2025/2026»; торішня Екстра-ліга — «BETKING Екстра-ліга 2025/2026»,
  позаторішня — «Favbet Екстра-ліга 2024/2025» (інший спонсор, лишається).
- **Команди (`TeamInfo`)**: поля `team_kind` (порожнє = клуб АФУ; «збірна», «іноземний клуб») і
  `country`. Суперники збірної/ЛЧ матимуть `Relevance = false`; у застосунку тап по ним не відкриває
  сторінку команди (у них нема ні складу, ні таблиці). Суперників ще не заведено.
- **Матчі (`Match`)**: поле `is_top` (топ-матч дня, один на добу, ставить CRM). Календар Екстра-ліги
  2026/27 залито повністю: 90 матчів у 18 турах; час матчів турів 6–18 поки **заглушка 14:00**
  (домашні Альянсу 16:00), АФУ уточнює в CRM.
- **Час матчу рівно 00:00 Києва означає «час не призначено»** — застосунок показує «—:—»; радимо так само.
- **Статуси матчу**: 1 запланований, 2 перенесений, 3 онлайн, 4 зіграний. **Статус 3 в базі ще жодного
  разу не ставили**: оператори переводять матч одразу з 1 у 4 після гри, тож «наживо» на сайті
  показувати поки нема чого; рахунок з'являється разом зі статусом 4.
- **Заявки 2026/27 неповні** (у ХІТ 5 гравців із 16, що виходили): у протоколах гравці зі старих
  заявок, тому статистика рахується за протоколом матчу, а не за заявкою; номери гравців можуть
  повторюватись усередині команди.
- **Асисти в протоколах майже не ведуться** (3 записи з 2054 голів) — стовпчик буде нулями.

## 4. Бренд

Кольори з оригінального логотипа АФУ: синій **#1676BC**, жовтий **#FFF200**. Повний двосторонній
логотип — `assets/brand/afu-logo-two-sided-2376.png` у репозиторії застосунку (2376×932, прозоре
тло). Логотипи змагань — з `seasons/overview`.

## 5. Що ще не готово і від кого залежить

- Рубрики й перша новина в CRM — адміністратор АФУ.
- Матчі Кубка України, турнір жіночої ліги, суперники збірної/ЛЧ, справжній час матчів — АФУ в CRM.
- Statscore для матчів Екстра-ліги — потрібен доступ від АФУ, у даних його нема.
- Перехід фан-застосунку з `futsal-news-api` на новини в Xano — після переїзду сайту.

Питання — в afu-crm#1 або новим issue в цьому репозиторії.
